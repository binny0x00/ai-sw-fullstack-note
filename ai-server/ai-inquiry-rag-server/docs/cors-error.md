# CORS 에러 대응 가이드

## 증상

프론트엔드에서 백엔드 API를 호출할 때 브라우저 콘솔에 CORS 관련 에러가 표시된다.
로그인 버튼을 눌러도 화면 변화가 없거나 API 응답을 받지 못하는 경우가 많다.

## 원인

백엔드 서버가 프론트엔드 origin을 허용하지 않았을 가능성이 높다.

## 확인 방법

- 브라우저 개발자 도구 Console 탭에서 CORS 에러 확인
- Network 탭에서 preflight OPTIONS 요청 실패 여부 확인
- 백엔드 CORS 허용 origin 설정 확인

## 해결 방향

개발 환경에서는 프론트엔드 주소를 백엔드 CORS 허용 목록에 추가한다.
예를 들어 프론트엔드가 `http://localhost:5173`에서 실행 중이면 해당 origin을 허용한다.
