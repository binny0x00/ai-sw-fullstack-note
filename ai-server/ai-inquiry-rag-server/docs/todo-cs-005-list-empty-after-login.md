# 로그인 후 목록이 비어 보이는 문의

## 상황

사용자가 로그인했는데 기존 Todo 목록이 모두 사라졌다고 문의한다.

## 확인 포인트

- 다른 이메일 계정으로 로그인했는지 확인한다.
- 필터가 완료 또는 특정 태그만 보기로 설정되었는지 확인한다.
- 서버 동기화 지연인지 확인한다.

## 답변 가이드

로그인한 이메일과 필터 설정을 확인하도록 안내한다. 계정이 다르면 기존 항목이 보이지 않을 수 있다.

## 개발팀 전달 기준

같은 계정에서 데이터가 사라진 것이 확인되면 데이터 손실 가능성이 있어 긴급도 high로 분류한다.
