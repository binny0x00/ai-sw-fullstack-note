# Todo 생성 실패 문의

## 상황

사용자가 새 할 일을 입력하고 저장을 눌렀지만 목록에 추가되지 않는다고 문의한다.

## 확인 포인트

- 제목이 비어 있거나 공백만 입력되었는지 확인한다.
- 네트워크 연결이 끊겼거나 API 서버 응답이 실패했는지 확인한다.
- 로그인 세션이 만료되어 저장 요청이 거절되었는지 확인한다.

## 답변 가이드

입력 내용을 다시 확인하고 새로고침 후 재시도하도록 안내한다. 반복되면 발생 시간, 입력한 제목, 화면 캡처를 요청한다.

## 개발팀 전달 기준

정상 입력에서도 저장 실패가 반복되면 GitHub Issue 생성을 권장합니다.
