# Todo 수정 내용 미저장 문의

## 상황

사용자가 할 일 제목이나 메모를 수정했지만 다시 열어보면 이전 내용으로 보인다고 문의한다.

## 확인 포인트

- 저장 버튼을 눌렀는지 확인한다.
- 오프라인 상태에서 수정했는지 확인한다.
- 여러 기기에서 동시에 같은 항목을 수정했는지 확인한다.

## 답변 가이드

수정 후 저장 완료 메시지가 표시되는지 확인하도록 안내한다. 여러 기기에서 동시에 수정했다면 마지막 저장 내용이 반영될 수 있음을 설명한다.

## 개발팀 전달 기준

저장 완료 메시지가 나왔는데 DB 값이 바뀌지 않으면 버그로 분류한다.
