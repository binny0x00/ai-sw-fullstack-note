# 필터 때문에 항목이 숨겨지는 문의

## 상황

사용자가 Todo가 사라졌다고 문의했지만 실제로는 필터 조건 때문에 보이지 않는 경우다.

## 확인 포인트

- 전체, 진행 중, 완료 필터 중 무엇이 선택되어 있는지 확인한다.
- 검색어가 입력되어 있는지 확인한다.
- 태그 필터나 날짜 필터가 켜져 있는지 확인한다.

## 답변 가이드

필터를 전체로 바꾸고 검색어를 지운 뒤 목록을 확인하도록 안내한다.

## 개발팀 전달 기준

필터 UI가 현재 상태를 명확히 보여주지 않아 반복 문의가 발생하면 UX 개선 이슈로 등록한다.
