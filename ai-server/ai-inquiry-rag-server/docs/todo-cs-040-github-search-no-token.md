# GitHub Issue 조회 토큰 누락 문의

## 상황

AI 검토 중 GitHub Issue 조회 결과를 사용할 수 없다는 메시지가 표시된다.

## 확인 포인트

- GITHUB_TOKEN이 설정되었는지 확인한다.
- 토큰 권한이 repository issue 조회를 허용하는지 확인한다.
- GITHUB_REPOSITORY 값이 올바른지 확인한다.

## 답변 가이드

관리자에게 GitHub 연동 설정을 확인하도록 안내한다.

## 개발팀 전달 기준

토큰 또는 repository 설정 누락은 운영 설정 이슈로 분류한다.
