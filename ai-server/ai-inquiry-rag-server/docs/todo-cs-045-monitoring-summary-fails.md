# 모니터링 요약 조회 실패 문의

## 상황

관리자 화면에서 모니터링 요약 조회 실패 메시지가 표시된다.

## 확인 포인트

- AI 서버가 실행 중인지 확인한다.
- `agent_step_logs`, `api_request_logs` 테이블이 있는지 확인한다.
- migration이 적용되었는지 확인한다.

## 답변 가이드

AI 서버 상태와 migration 적용 여부를 확인하도록 안내한다. 로그 테이블이 없어도 화면은 0값으로 표시되어야 한다.

## 개발팀 전달 기준

모니터링은 보조 기능이므로 실패해도 주요 게시판 기능을 막으면 안 된다.
