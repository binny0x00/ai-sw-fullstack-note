# 로그인 후 401 오류 문의

## 상황

사용자가 로그인했지만 Todo 저장 시 401 unauthorized 오류가 발생한다고 문의한다.

## 확인 포인트

- access token이 localStorage에 저장되었는지 확인한다.
- 요청 header에 Authorization이 포함되는지 확인한다.
- JWT 만료 시간이 지났는지 확인한다.

## 답변 가이드

다시 로그인 후 재시도하도록 안내한다. 반복되면 브라우저와 발생 시간을 요청한다.

## 개발팀 전달 기준

로그인 직후 401이 반복되면 인증 처리 버그로 분류한다.
