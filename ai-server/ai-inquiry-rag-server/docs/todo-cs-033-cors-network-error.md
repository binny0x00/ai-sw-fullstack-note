# 네트워크 또는 CORS 오류 문의

## 상황

사용자가 화면에서 저장 실패가 발생하고 개발자 도구에 CORS 또는 network error가 보인다고 문의한다.

## 확인 포인트

- 프론트엔드 API base URL이 올바른지 확인한다.
- 백엔드 서버가 실행 중인지 확인한다.
- CORS 허용 origin 설정이 배포 주소와 일치하는지 확인한다.

## 답변 가이드

사용자에게는 일시적인 서버 연결 문제로 안내하고, 내부적으로 서버 설정을 확인한다.

## 개발팀 전달 기준

CORS, API URL, 서버 연결 문제는 개발팀 확인이 필요한 technical issue로 분류한다.
