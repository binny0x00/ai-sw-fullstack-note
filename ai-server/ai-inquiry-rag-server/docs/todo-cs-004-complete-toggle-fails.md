# 완료 체크 상태 변경 실패 문의

## 상황

사용자가 할 일을 완료 처리했지만 체크 표시가 유지되지 않는다고 문의한다.

## 확인 포인트

- 체크 직후 다시 원상복구되는지 확인한다.
- 필터가 미완료 보기로 설정되어 완료 항목이 숨겨진 것인지 확인한다.
- 로그인 세션 만료로 상태 변경 요청이 실패했는지 확인한다.

## 답변 가이드

현재 필터 설정과 새로고침 후 상태를 확인하도록 안내한다. 반복되면 항목 제목과 발생 화면을 요청한다.

## 개발팀 전달 기준

완료 상태 API가 실패하거나 성공 후 상태가 반영되지 않으면 GitHub Issue 생성을 권장한다.
