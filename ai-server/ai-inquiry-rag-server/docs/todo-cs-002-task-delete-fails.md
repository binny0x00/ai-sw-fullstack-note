# Todo 삭제 실패 문의

## 상황

사용자가 완료했거나 잘못 만든 할 일을 삭제하려고 했지만 항목이 계속 남아 있다고 문의한다.

## 확인 포인트

- 삭제 버튼을 누른 뒤 에러 메시지가 표시되었는지 확인한다.
- 본인이 만든 항목인지, 공유 목록의 권한 제한이 있는지 확인한다.
- 삭제 후 목록이 자동 갱신되지 않는 UI 문제인지 확인한다.

## 답변 가이드

새로고침 후 항목이 남아 있는지 확인하도록 안내한다. 계속 남아 있으면 항목 제목과 발생 시간을 요청한다.

## 개발팀 전달 기준

삭제 API는 성공했지만 화면에 남거나, 삭제 API가 반복 실패하면 개발팀 확인이 필요하다.
