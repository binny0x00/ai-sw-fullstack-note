# 08. 성능 평가용 테스트 데이터

## 1. 일반 사용자 계정

실제 비밀번호를 문서에 기록하지 않습니다. 아래는 역할만 설명합니다.

```text
user-a: 일반 사용자
user-b: 일반 사용자
manager-a: DB에서 role을 MANAGER로 변경한 담당자
```

관리자 승격:

```sql
UPDATE users
SET role = 'MANAGER'
WHERE email = 'manager@example.com';
```

## 2. 게시글 테스트 데이터

### 2.1 단순 질문

제목:

```text
태그는 어떻게 입력하나요?
```

본문:

```text
게시글 작성 화면에서 태그를 여러 개 입력하고 싶은데 어떤 형식으로 입력하면 되나요?
```

기대:

```text
suggested_action: answer_only
```

### 2.2 버그 문의

제목:

```text
로그인 버튼을 눌러도 반응이 없습니다
```

본문:

```text
Chrome에서 로그인 버튼을 클릭해도 화면이 바뀌지 않습니다.
개발자 도구 콘솔에는 CORS 관련 에러가 보입니다.
```

기대:

```text
inquiry_type: bug 또는 account
suggested_action: github_issue_recommended 또는 needs_human_review
```

### 2.3 기능 요청

제목:

```text
자동 로그인 기능을 추가해 주세요
```

본문:

```text
매번 로그인해야 해서 불편합니다. 브라우저를 닫았다가 다시 열어도 로그인 상태가
유지되는 자동 로그인 기능이 있으면 좋겠습니다.
```

기대:

```text
inquiry_type: feature_request
suggested_action: github_issue_recommended
```

### 2.4 검색 테스트

제목:

```text
게시글 검색 결과가 이상합니다
```

본문:

```text
검색어를 입력했는데 제목에는 없는 글도 나오고, 본문에 있는 글은 누락되는 것 같습니다.
```

기대:

```text
게시글 검색 기능 점검
```

### 2.5 권한 테스트

제목:

```text
다른 사람이 제 게시글을 수정할 수 있나요?
```

본문:

```text
제가 작성한 게시글을 다른 일반 사용자가 수정하거나 삭제할 수 있는지 확인하고 싶습니다.
```

기대:

```text
일반 사용자는 본인 게시글만 수정/삭제 가능
MANAGER는 관리 가능
```

## 3. 댓글 테스트 데이터

버그 문의 게시글에 아래 댓글을 추가합니다.

```text
담당자: 어떤 브라우저와 OS에서 발생하나요?
사용자: macOS Chrome에서 발생합니다.
담당자: 네트워크 탭에서 API 응답 상태도 확인해 주세요.
사용자: OPTIONS 요청이 실패하는 것 같습니다.
```

이 댓글 대화가 AI 문의 컨텍스트에 포함되어야 합니다.

## 4. RAG 테스트 질의

```text
로그인 CORS 오류 해결 방법
JWT 만료 시 재로그인 처리
자동 로그인 기능 요청
게시글 검색 품질 개선
GitHub Issue로 등록해야 하는 문의 기준
```

## 5. 결과 판정 기준

| 데이터 | 성공 기준 |
| --- | --- |
| 단순 질문 | 답변 초안이 댓글로 바로 사용 가능하다 |
| 버그 문의 | 원인 후보와 점검 방법이 포함된다 |
| 기능 요청 | GitHub Issue 등록 권장이 나온다 |
| 댓글 포함 문의 | 댓글 대화 내용이 답변에 반영된다 |
| 권한 테스트 | 일반 사용자와 MANAGER 동작이 다르다 |
